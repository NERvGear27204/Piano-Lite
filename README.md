# 开发原因（碎碎念）
这是一个由AI和我花了6个小时。迭代了二十几个版本出来的钢琴APK，适用于安卓12，主体由Java编写，音频引擎由C语言编写。
我苦于找不到好用的钢琴APP，好用的太大而且有开屏摇一摇广告（说的就是你完*钢琴！），体积小的按键延迟很高（名字好像叫移动音乐家），界面又很复古，而且没有夜间模式。虽说不要重复造轮子，但这次体验Vibe Coding还是很有意思的，于是上传至GitHub留作纪念。

软件目前确实很好用，也没有什么bug，欢迎大家下下来试试吧~

有两个版本：一个是钢琴加方波版本，一个是单独的方波版本，钢琴加方波版本4兆，方波版本只有60kb非常逆天，除此之外没有区别，方波音色的好处是在嘈杂环境中容易听清，大家根据需要选择即可。

# 版本日志
- PianoLite.apk为第一版正式版
    - 采用纯java编写，建模方波发声，非常小巧，仅24.7K，但是受到编程语言限制，延迟最低也只能这样了，简单弹奏可以满足。

- PianoSample.apk为第二版正式版
    - 采用C语言编写音频引擎，极大优化了延迟，在安卓12上可以做到实时弹奏。遇到并解决了爆音问题。增加了钢琴音色，由于是采样音源，体积也因此变大了很多。

- “PianoSquare.apk”为第二版的精简版
    - 去除钢琴音色，纯方波发声。仅60k

- “Piano Lite.apk”为第三版正式版
    - 滑块移动更平滑
    - 点击滑条不触发界面跳变
 
- “Square Lite.apk”为第三版的精简版
    - 去除钢琴音色，纯方波发声。仅60k
